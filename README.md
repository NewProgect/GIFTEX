# GIFTEX — Telegram Mini App starter

Это стартовый MVP: адаптивная витрина, поиск, фильтры, локальные демо-объявления и Telegram WebApp SDK.

## Что уже работает
- Открытие из Telegram-бота через кнопку Web App.
- Каталог демонстрационных подарков.
- Поиск и фильтрация.
- Добавление демо-объявлений (сохраняются только в браузере пользователя).
- Профиль Telegram, если приложение открыто внутри Telegram.

## Что НЕ подключено
- Реальная база данных и общая лента объявлений.
- Проверка владения подарком.
- Покупка, escrow/безопасная передача, возвраты.
- Автоматическое удержание комиссии.
- Реальная синхронизация с Telegram Gifts API.

Не принимай оплату за «покупку» через текущий интерфейс: кнопки покупки пока демонстрационные.

## Запуск бота
Нужен Python 3.10+.

```bash
pip install -r requirements.txt
```

Установи переменные окружения:
- `BOT_TOKEN` — токен от @BotFather (никому его не отправляй).
- `WEBAPP_URL` — публичный HTTPS URL файла `index.html`.

Linux/macOS:
```bash
export BOT_TOKEN="твой_токен"
export WEBAPP_URL="https://твой-домен/index.html"
python bot.py
```

Windows PowerShell:
```powershell
$env:BOT_TOKEN="твой_токен"
$env:WEBAPP_URL="https://твой-домен/index.html"
python bot.py
```

## Как опубликовать Mini App без бюджета
1. Загрузи `index.html` на статический хостинг, который выдаёт HTTPS (например, GitHub Pages).
2. Включи GitHub Pages для репозитория и скопируй HTTPS-ссылку.
3. В `WEBAPP_URL` укажи именно эту ссылку.
4. Запусти бота на компьютере. Пока компьютер выключен, бот не работает.

## Важно перед реальными сделками
Нужен backend с базой данных, серверная проверка `Telegram.WebApp.initData` (не доверяй `initDataUnsafe`), система статусов объявлений, проверка продавца/владения подарком, безопасный процесс передачи и расчёта комиссии. Не проси у пользователей коды входа, пароли или доступ к аккаунту.

Для реальных Telegram collectible gifts изучи актуальные официальные методы Telegram/TON и правила площадок. Не выдавай тестовые карточки за реальные предложения.
